# Patient Event Ingest Service

This project is the foundation for a production-minded NestJS service that will ingest patient events. The current increment intentionally provides only a health endpoint; event ingestion and persistence will be added later.

## Prerequisites

- Node.js 24 LTS (use `nvm use` with the included `.nvmrc`)
- npm

## Commands

```bash
npm install
npm run start
npm run start:dev
npm run lint
npm run typecheck
npm run build
npm test
npm run test:e2e
```
